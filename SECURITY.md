# Security

Found a security problem? Please give me a quiet heads-up rather than opening a
public issue or posting the details in a pull request.

## Report it privately

Use GitHub's [private vulnerability reporting form](https://github.com/blowdart/JerryChart/security/advisories/new).
You can also find it under **Security -> Advisories -> Report a vulnerability**.
Private reporting is enabled for this repository.

Please include:

- What you found and what someone could do with it.
- Steps to reproduce it, ideally with a small example.
- The commit or version you tested, and any relevant setup details.

Please leave out real passwords, API keys, and other people's personal data.
Test on your own instance and accounts, not someone else's.

This is a personal project, so I can't promise a response time, but I'll do my
best to take a look and work with you on a fix. Please keep the details private
until we've agreed it's safe to share them.

## What's supported?

Security fixes go into `main`. Older commits and branches don't have a separate
support window, so please check whether the problem still exists on `main`.

For ordinary bugs that aren't security-sensitive, a public issue is fine.
Thanks for helping keep this little project safe.
